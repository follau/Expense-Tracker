# Expense Tracker

## Автор
Абашин Алексей

## Описание
Expense Tracker — это GUI-приложение на Python для отслеживания личных расходов.

### Возможности:
- Добавление расходов
- Фильтрация по категории
- Фильтрация по дате
- Подсчёт суммы за выбранный период
- Сохранение данных в JSON
- Загрузка данных из JSON

## Как использовать
1. Запустить программу:
`python main.py`

2. Ввести:
- сумму
- категорию
- дату (YYYY-MM-DD)

3. Нажать **Добавить расход**

4. Использовать фильтры для поиска расходов.

## Примеры использования
- 250 | еда | 2026-05-05
- 100 | транспорт | 2026-05-06
- 500 | развлечения | 2026-05-07
